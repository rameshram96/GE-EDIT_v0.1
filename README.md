# GE-EDIT (React + FastAPI)
1. Copy your existing `modules/` folder into `backend/`.
2. Backend:  cd backend && pip install -r requirements.txt && uvicorn api:app --reload --port 8000
3. Frontend: cd frontend && npm install && npm run dev   (open http://localhost:5173)
Logos: replace the ICAR/IARI circles in Navbar (App.jsx) with <img src="/ICAR_logo.png"> from frontend/public.
